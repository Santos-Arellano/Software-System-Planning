# Database Version Control con Liquibase

## Descripción del Proyecto

Este proyecto implementa un sistema de control de versiones para bases de datos Oracle utilizando Liquibase. Permite gestionar migraciones de esquemas de base de datos de forma controlada entre diferentes entornos (desarrollo y producción).

## Estructura del Proyecto

```
DB_Palomera/
├── changelog.xml                    # Changelog maestro
├── changesets/                      # Directorio de changesets SQL
│   ├── 001-initial-schema.sql      # Esquema inicial
│   └── 002-add-users-table.sql     # Tabla de usuarios
├── liquibase-dev.properties        # Configuración desarrollo
├── liquibase-prod.properties       # Configuración producción
└── README.md                       # Este archivo
```


## Prerrequisitos

- Docker instalado
- Acceso a bases de datos Oracle (desarrollo y producción)
- Usuarios de base de datos con permisos adecuados


## Configuración

### 1. Alias de Docker para Liquibase

```bash
alias liquibase='docker run --rm -v "$(pwd)":/liquibase/workspace -w /liquibase/workspace liquibase/liquibase'
```


### 2. Configuración de Base de Datos

#### Desarrollo (`liquibase-dev.properties`)

```properties
changeLogFile=changelog.xml
url=jdbc:oracle:thin:@//host.docker.internal:1521/FREEPDB1
username=dev_user
password=dev_password
driver=oracle.jdbc.OracleDriver
```


#### Producción (`liquibase-prod.properties`)

```properties
changeLogFile=changelog.xml
url=jdbc:oracle:thin:@//host.docker.internal:1522/FREEPDB1
username=prod_user
password=prod_password
driver=oracle.jdbc.OracleDriver
```


### 3. Permisos de Oracle

Los usuarios necesitan quota en tablespace:

```sql
ALTER USER DEV_USER QUOTA UNLIMITED ON USERS;
ALTER USER PROD_USER QUOTA UNLIMITED ON USERS;
```


## Changesets Implementados

### 001-initial-schema.sql

Crea la tabla inicial del sistema:

```sql
CREATE TABLE example (
    id NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    name VARCHAR2(255) NOT NULL
);
```


### 002-add-users-table.sql

Añade tabla de usuarios:

```sql
CREATE TABLE users (
    user_id NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    username VARCHAR2(50) NOT NULL,
    email VARCHAR2(255) NOT NULL
);
```


## Comandos Principales

### Verificar Estado

```bash
# Desarrollo
liquibase --defaultsFile=liquibase-dev.properties status

# Producción
liquibase --defaultsFile=liquibase-prod.properties status
```


### Aplicar Cambios

```bash
# Desarrollo
liquibase --defaultsFile=liquibase-dev.properties update

# Producción
liquibase --defaultsFile=liquibase-prod.properties update
```


### Ver Historial

```bash
# Desarrollo
liquibase --defaultsFile=liquibase-dev.properties history

# Producción
liquibase --defaultsFile=liquibase-prod.properties history
```


### Generar Documentación

```bash
liquibase --defaultsFile=liquibase-dev.properties dbDoc docs/
```


### Rollback (si es necesario)

```bash
# Rollback al changeset anterior
liquibase --defaultsFile=liquibase-dev.properties rollback-count 1
```


## Flujo de Trabajo

1. **Desarrollo de Cambios**
    - Crear nuevo archivo SQL en `changesets/`
    - Añadir referencia en `changelog.xml`
    - Probar en desarrollo
2. **Verificación**

```bash
liquibase --defaultsFile=liquibase-dev.properties status
liquibase --defaultsFile=liquibase-dev.properties update
```

3. **Despliegue a Producción**

```bash
liquibase --defaultsFile=liquibase-prod.properties status
liquibase --defaultsFile=liquibase-prod.properties update
```


## Archivos de Configuración

### changelog.xml

```xml
<?xml version="1.0" encoding="UTF-8"?>
<databaseChangeLog
    xmlns="http://www.liquibase.org/xml/ns/dbchangelog"
    xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
    xsi:schemaLocation="http://www.liquibase.org/xml/ns/dbchangelog
    http://www.liquibase.org/xml/ns/dbchangelog/dbchangelog-latest.xsd">

    <changeSet id="001-initial-schema" author="santosa">
        <sqlFile path="changesets/001-initial-schema.sql"/>
    </changeSet>

    <changeSet id="002-add-users-table" author="santosa">
        <sqlFile path="changesets/002-add-users-table.sql"/>
    </changeSet>
</databaseChangeLog>
```


## Buenas Prácticas

1. **Naming Convention**: Use formato `XXX-descripcion-cambio.sql`
2. **Atomicidad**: Un cambeset por archivo SQL
3. **Testing**: Siempre probar en desarrollo primero
4. **Backup**: Respaldar antes de aplicar en producción
5. **Documentation**: Comentar cambios complejos en SQL

## Troubleshooting

### Error de Quota Oracle

```
ORA-01950: The user has insufficient quota on tablespace USERS
```

**Solución**: `ALTER USER username QUOTA UNLIMITED ON USERS;`

### Error de Licencia Liquibase Pro

**Solución**: Usar la versión open source con el alias correcto

### Error de Conexión

**Solución**: Verificar URLs, puertos y credenciales en archivos `.properties`
